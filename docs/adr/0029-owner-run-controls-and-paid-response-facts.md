# ADR-0029：Owner运行控制与已发生的调用事实

状态：已采用。日期：2026-10-01。

暂停和停止表达Owner决定，不能证明供应商已中止调用。保留原processing_jobs执行状态、receipt、checkpoint和冻结输入；新增独立控制修订、停止标志、排队优先级及方向/类别暂停记录，不增加取消终态或删除调用事实。

领取在同一事务检查控制状态并增加控制修订，与旧窗口停止/优先级竞争。排队停止保留任务但不允许领取；Owner可明确恢复尚未外发的排队任务。已领取任务通过最新修订请求停止。优先级仅参与合格任务排序，既有来源策略、预算、日限额与未知结果检查继续执行。

新任务插入在数据库准入触发器检查暂停，包含阶段续接及既有明确重试路径，避免不同入队入口遗漏。类别由冻结任务类型及输入确定，旧数据只回填可证明的类别。方向使用稳定来源类型与ID；删除成果不会删除独立Owner动作事实。

外发边界在持久记录remote_call_started的事务内检查控制。响应返回后仍保存checkpoint与receipt；结果应用与控制检查在同一业务事务内进行，暂停或停止先提交则不应用正文、回顾题或ASR建议，不再接纳下一阶段。若应用事务已经先提交，随后停止不回滚已完成的事实。暂停/停止不主动取消在途请求，因此不能保证供应商停止计费。

暂停持续到明确恢复。恢复只解除准入阻断；失败或未知结果沿既有明确重试语义核对，已知响应保留其原付费身份，未知结果可能再次收费。该机制覆盖个人知识文章、增量更新、每周回顾生成与私人语音转录；其它创作/来源处理流程继续使用其既有控制契约。
