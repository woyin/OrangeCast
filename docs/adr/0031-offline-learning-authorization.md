# ADR-0031：明确授权的离线学习副本

2026-10-02，实施中的工程决策；实体手机行为另验。

离线功能默认关闭，Owner在线登录后明确授权当前设备。每次授权生成新的 namespace，绑定不可逆的登录session指纹、设备UUID、实例epoch和24小时期限；清单没有cookie、密钥或CSRF值。Server启动轮换实例epoch，避免数据库备份恢复重新激活旧浏览器授权。浏览器音频与待同步草稿不进入服务器备份。

只缓存版本化的静态专用外壳及明确下载的内容，通用SSR、登录、设置、自动化任务、CSRF和私人录音不缓存。首版下载本地EvidenceAudio和选定转录、笔记、通过文章；拒绝远端节目URL、DJ、私人录音。设备总10来源/500MiB，浏览器可用配额50%另有更严限制。文件完整SHA/size核对才ready，索引仍存在不能证明Blob仍在。

只有完整原音提供200/单Range206/错误416。定位保持source/snapshot/audioSHA及真实时间，不使用Blob URL构造身份。换转录或原音不静默重定位。

回网先检查session/epoch/来源，再显示和同步；撤回立即停媒体并清理相应下载，拒旧操作。断网无法实时知道服务端撤回，只在已有期限运行并明确提示。期限是应用策略，不承诺抵抗用户篡改本机时钟/存储。

本地outbox只保存文字笔记、整理草稿、原音进度与已冻结补听区间进度，保存schema、namespace、UUID、edited_at、expectedRevision、来源快照和整个命令hash。补听身份包含现有excerpt、冻结snapshot/version/audioSHA、起止时间与segment列表；服务端核验清单和真实区间，独立CAS更新补听进度，不覆盖原音进度。Owner明确前台同步；服务端合法写入和回执同事务，同UUID/hash丢ack重放没有第二笔，同UUID异hash与CAS冲突保留客户端文字。源缺失不得静默改绑；ASR、生成、预算和任务控制不入outbox，不依赖Background Sync。

新SW只在每个静态资源实际hash验证完成后安装。播放、录音或同步在途不能强制激活/刷新，schema不兼容阻止同步但保留可复制文字。下载清理独立于待同步文字，登出则清理该session所有私有副本并广播其它标签。

边界：浏览器存储可能失败/被驱逐，实体手机后台播放、录音及更新行为在独立验收表逐项待证。旧namespace锁定草稿可复制，不能在新登录直接自动同步。
