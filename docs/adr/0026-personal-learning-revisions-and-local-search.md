# 个人学习修订与本地检索

知识文章保留不可变正文与材料快照，将工作稿、最近通过版、具体审校和依据有效性分开。一次迟到的模型结果只能增加自己的执行记录，不能替换 Owner 后来的编辑；保留旧通过版能继续阅读，同时导出仍须核查其确切依据。

统一检索使用 SQLite FTS5 和确定性的中文双字词投影。为了让业务变更、索引和回填保持同一事务，SQL 触发器调用由 Store 初始化注册的确定性 Go 函数；直接用外部 SQLite 工具写业务表必须具有这些函数，因此维护和重建通过应用执行。与独立异步索引相比，这承担了应用运行时依赖，换取没有索引延迟窗口及可重复的升级/恢复。索引可重建，不能成为可独立编辑的第二份正文。

旧字符哈希向量只保留为离线对比资料。默认检索通过固定10例、1万条投影的指标；跨语言仅支持明确列出的词汇别名，不宣称一般语义理解。没有启用远端 embedding 或收费搜索 GET，也不假定聊天端点兼容 embedding；未来启用需独立连接、价格、发送策略与同输入评测。
