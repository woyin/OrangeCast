# 第四轮个人听学使用说明

本页说明当前源码中的操作入口和边界，不代表已部署、真实模型质量通过或实体手机体验通过。完整开发状态以[原子任务清单](superpowers/plans/2026-10-01-personal-learning-and-knowledge-articles-v4-tasks.md)和[验证记录](superpowers/plans/2026-10-01-personal-learning-and-knowledge-articles-v4-validation.md)为准。既有收听、录音、回顾操作见[第三轮说明](personal-learning-v3.md)。

## 开始一次学习

1. 从首页继续原音，或在 `/search` 用全文搜索找回来源、重点、笔记及文章。全文检索不需要语义模型连接。
2. 在 `/questions` 记录问题和目标，明确关联可用材料。问题关联不是证据证明；材料变化后核对原快照再使用。
3. 保存随听笔记时核对实际播放器来源和原音位置。听后整理入口是 `/listening-reflections`；整理文字与已保存笔记分别保留，不因读取或刷新自动启动 AI。
4. 在问题详情打开“我的理解”页面 `/questions/{问题ID}/understandings`，写自己的结论、选择需要的精确版本参考材料并明确确认保存。每次保存生成不可变版本；保存与“明确选择此版本为当前答案”是两个动作，不自动解决问题。当前版本和历史分别展示。可以导入笔记或采用模型内容为编辑器草稿，确认勾选重置，核对并明确保存才成为个人理解。可以不选来源参考，但不会因此变成来源事实。
5. 在 `/knowledge-articles` 选择问题或材料，触发发现、选材、写作和独立审校。未通过工作稿与最近通过版本分开，修改不会覆盖旧通过版。

来源摘录冻结来源快照和 Segment ID；引用时间取原音位置，而不是 DJ 清单偏移或累计播放时长。来源清理后不能通过旧引用继续读取已删除正文；保留的个人文字仍须区分“我的理解”与来源摘录。

## 材料缺口与补听

问题详情的“材料缺口与补听”进入 `/questions/{问题ID}/gaps`。记录例子、反例、限定条件、比较或实践等缺口，区分程序检查、模型建议和 Owner 判断；默认待处理。点击“找已有材料（本地）”最多列出 20 项当前真实索引材料或未处理来源标题，不调用模型，不改变权限，不证明检验了全库。

核对后明确关联到问题。音频快照、Segment 和原音 hash 有效时可“将真实区间加入补听”；文档候选仅阅读，不制造音频区间。补听是队列中的独立 excerpt 模式，不覆盖原音或 DJ 的进度。听完不自动解决缺口；明确选择“有帮助、仍不足、暂不处理、重新待处理”保留历史。问题正文或范围改变后旧判断失效，重新核对；多窗口版本冲突保留文字，不能按旧判断自动关联。

当前选定问题有待处理缺口时，首页下一步卡提示补材料，并注明没有检验全库。这是本地下一步建议，不是已经证明问题完整性或自动探索的结论。

## 模型权限与语义搜索

“我的理解”新版本默认仅本地。允许外发或仅指定 Provider 是明确保存的版本策略；调用模型还必须满足每个实际参考来源的权限。修改策略不补写旧版本，也不自动启动付费调用。清理来源时保留 Owner 回答正文，移除参考正文，并使依赖引用或文章任务失效。语义索引还需明确选择当前理解快照；有来源参考时相关来源也须在索引范围中，切换当前答案使旧选择失效。

语义索引连接独立使用 `LEARNING_EMBEDDING_*`，不复用文章或转录密钥。配置连接不等于开启：需要明确预检、登记价格、建立对应模型及维度的索引，并满足当前质量准入。`/search` 的设置入口为 `/search/settings`；显式语义动作通过 `/api/knowledge-semantic` 持久任务处理。默认关闭；未通过有效准入时仍使用 FTS。预检会向模型发送请求，可能计费。

索引外发授权与普通语义检索开启分开。设置页保存明确来源、理解快照、准确模型输入价格和容量后重建索引，同时关闭旧语义状态。设置发生版本冲突应重新核对，不继续旧授权。

设置页提供质量报告 JSON 模板。报告需 Owner 实际测量确认，至少 40 条查询、20 个冷样本，并记录 2048 维、1 万/5 万规模的查询/素材/相关性 hash、运行代码与机器、冷热 p95、峰值内存和已知费用。准入要求 Recall 不低于 FTS、改写查询收益至少 0.1、冷 p95 分别不高于 150/500 毫秒；报告导入不调用模型，也不自动开启，仍须另行激活。源码、机器、范围、配置、索引 epoch、价格或理解选择变化都会使旧准入失效，不能用热缓存替代冷启动结果。

评测准备单条查询可在设置页明确提交（`/api/knowledge-semantic` 的 `evaluation_query`），这是可能付费的持久任务，冻结版本与预算，但不激活普通搜索。只读 `/api/knowledge-search-settings?config_id=...` 返回当前报告、失效原因及 `effective_semantic_enabled`；另加 `action=evaluate&q=...` 比较既有向量的 FTS/hybrid，GET 不生成向量、不付费。普通 `query` 仍须通过完整门禁。批量只读评测现可使用 `scripts/semantic-quality-eval.py`，见[真实质量评测说明](semantic-quality-evaluation.md)。真实配置与人工标注仍未齐备，不能据合成向量 benchmark 宣称真实 Recall 收益。最新同机2048维、20样本冷p95为107.1/499.6毫秒，低于150/500ms门槛；50k仅有0.4ms余量，尚不代表不同负载下稳定达标，实际语义继续关闭。[最新对照结果](superpowers/validation/semantic-optimization-v2/README.md)保留样本与内存代价，[上一轮记录](superpowers/validation/semantic-optimization/README.md)保留历史结果。完整原始证据见[语义性能记录](superpowers/validation/v4/semantic-performance.md)。

## 问答、写作与费用

问题学习对话冻结当时的问题版本及材料，回答生成与范围检查分别记录任务，只有通过业务校验后才采用结果。AI 讲解标为“非原文”，参考链接不等于逐字可核验证据。

旧单来源 StudyChat 仍使用 `/api/study-chat`，历史入口 `/api/study-chat/history` 保留。新客户端须在首次提交前保存 UUID `request_key`；缺少该身份返回 **428 / `request_identity_required`**，不会自动调用模型。接受的请求返回异步任务状态，通过 `/api/study-chat/status` 查原请求或任务；失败后显式使用 `/api/study-chat/retry`。第三方旧客户端应升级提交和轮询流程，不能遇到 428 后盲目重复 POST。

文章用途为默认综合、知识解释、观点对比、实践指南，默认自动完成。勾选“先预览并确认写作计划”后在选材完成时暂停；查看、编辑和保存大纲不调用模型。先保存，再明确确认继续写作和审校。用途、材料、配置及计划版本冻结；其他窗口修改产生冲突时保留输入并重新核对。按另一用途修订会形成新修订并重新审校，旧通过版仍可读。

后台文章自动生成默认关闭；开启后的默认日限额是 1 篇，素材更新等待 30 分钟。用途和先确认计划的偏好在文章页面明确保存后才影响后续任务。反馈“有用、太浅、重复、归因不准”不会自行修改写作偏好。`/quality-cases` 中接受案例、分类事实和生成私有评测清单分别处理；接受案例不代表诊断已经成立。

`POD_*` 连接完整配置后，独立角色模型留空回退到基础模型；问题学习生成及审校使用各自覆盖项。价格由 Owner 在模型价格表维护，预算中的金额单位为分。预估、已知实际用量和未知远端结果分别记录，未知不能记成零成本；启用预算却缺少价格时付费任务应拒绝，不以免费估算绕过门禁。

在 `/automation` 查看冻结输入、任务状态、费用和控制。暂停类别或方向不撤销已发生调用，停止不抹除用量。响应丢失先查询原请求；已持久保存的模型响应恢复时复用，不再次付费生成。远端结果未知只能在明确知晓可能重复收费后新建重试尝试。来源撤回、停止或清理后，迟到结果不能自动进入正文。

## 私有文章质量评测

文章案例明确接受后可用 `cmd/quality-eval` 对一个冻结案例执行独立写作与审校。默认只生成私有预览，不调用模型；`--run` 才明确授权运行。例中的路径和案例 ID 均须换成真实实例及已接纳案例：

```sh
go run ./cmd/quality-eval --db /private/data/cloudwisepod.db --case "已接纳案例ID" --output /private/eval/case-a
go run ./cmd/quality-eval --db /private/data/cloudwisepod.db --case "已接纳案例ID" --output /private/eval/case-a --run
```

阶段先持久冻结估价和预算准入，再以 CAS 派发锁开始请求；月度用量 receipt 幂等记账。已知缓存重放不再调用模型，但仍复核当前权限。未知用量或价格不填零，远端结果未知不盲目重发。请求与实际响应模型不匹配时保留实际 token 数值并严格拒绝采用结果，不能用请求模型价格冒充实际费用。评测输出私有保存，不更新文章、学习问题或个人理解。

本轮仅有自建材料真实写作调用，返回输入 1428、输出 983 tokens；实际模型身份与冻结请求不一致，结果按规则拒绝，未继续独立审校。它证明收到真实 usage，不能证明文章质量通过。尚无真实审校和人工评分通过记录；个人真实笔记材料也不足，不能用合成案例宣称个人使用质量完成。

## 学习资料导出与备份

`/learning-exports` 从实际问题或跨集主题标题下拉选择范围，无需输入内部 ID；先预览数量和选项，再确认生成 ZIP。启用 JS 时统一表单处理预览和确认，页面轮询保留当前范围及选项；无 JS 时仍可使用 SSR 表单。历史、草稿、来源摘录均需显式勾选；默认不包含。后台生成不调用模型，刷新和轮询不会重新生成。预览或确认返回 404/409 时在原页面保留范围、选项与未提交文字，重新预览后再确认；失效下载不会自动跳走或丢弃草稿。播放、下载或其他动作在途时遵守页面切换守卫，完成或取消后再离开。

单包最多 500 个对象、100 MiB；同时有效预览及导出各有 100 条容量限制。导出文件保留 24 小时，以服务端时间和记录为准。下载时重新核对权限和冻结范围；素材变化、撤回、来源清理或到期后重新预览，不能从旧缓存下载。临时 ZIP 私有保存，包含本地 Markdown 和索引，用于阅读整理；它不是可恢复数据库备份，也不带模型密钥。

整实例迁移使用 `cloudwisepod backup` / `restore` 的 v2 包。备份包含数据库、证据音频和明确保留的私人录音，兼容恢复 v1；数据库设置可能包含 Provider 密钥，应私有保管。临时未保存录音、Narration 和浏览器离线副本不属于长期备份。恢复或服务端重启会更换离线 epoch，旧设备授权须重新在线核对。命令见[README 备份与恢复](../README.md#备份与恢复)。

## 离线听与学

在线登录后打开 `/offline`，明确“授权此设备”。需要 HTTPS 安全上下文（本机 localhost 可用于开发）、Service Worker、IndexedDB 与可用配额；不支持时继续在线使用。离线静态壳 scope 为 `/`，缓存范围仍是明确版本的静态资源，不缓存动态 SSR、登录页面、认证响应或任意请求。

单设备授权最长 24 小时，绑定当前登录、设备 namespace 和实例 epoch。从标题列表勾选来源、通过文章或真实补听区间并明确下载，最多 10 个来源、合计 500 MiB，浏览器实际配额可能更小。只下载真实本地 EvidenceAudio 及允许的学习资料；不下载 DJ、Narration、私人语音录音或远程音频地址。完整长度和 SHA256 验证后才可显示已就绪。取消、驱逐或校验失败须重新明确下载，不能把不完整缓存用于播放。

离线壳显示并播放已下载原音，保存笔记、整理文字和原音进度到本地待同步队列；冻结的补听区间含快照、Segment、原音 hash 和起止位置，持续播放器离线桥支持独立 excerpt 进度，不写成整集进度。专用离线壳在原音旁显示冻结的补听区间按钮，区间内 seek、暂停和刷新恢复仍保持同一身份，独立补听进度待明确同步；不自动播放刷新恢复的原音。每条操作冻结 UUID、载荷 hash、来源快照及版本。回网先核授权，再点击“明确同步待同步操作”。不做后台隐式上传，不触发 AI、ASR、发布或导出。响应丢失重放同一身份可去重；版本或来源冲突时保留文字供核对，不自动改绑到新的来源。已同步整理文字可通过在线核对后的离线草稿入口重新读取；来源删除后保留 Owner 文字并标明来源不可用。

授权到期、时钟异常或回网核对失败后停止播放并锁定私有内容。断网不能实时得知另一设备的来源撤回，24 小时只是限制旧副本的窗口，不防本机篡改。只清理下载副本不删除待同步文字；“撤回授权并清理本设备”、在线登出或换登录会清理私有设备数据，退出前先同步或复制重要文字。浏览器清站点数据或驱逐也可能丢失本地资料，不能当作备份。

旧本地 schema/协议不兼容时仅提供同会话文字只读复制，不自动迁移、播放或同步；新登录隔离旧私有内容。相同文件重下优先复用完整校验副本，否则暂存后原子发布，失败保留原 ready 副本；未完成下载可独立取消清理。

新 Service Worker 先等待；播放、录音、下载或同步在途时不能强制切换。各标签停止在途操作后明确确认安全更新。坏静态资源不能替换仍可用的旧版本。实体手机录音、锁屏后台 15 分钟、离线重开和更新体验仍需按[手机验收表](acceptance/2026-10-02-v4-offline-mobile.md)记录真实设备结果。

## 异常恢复

| 现象 | 操作 |
| --- | --- |
| 428 旧学习对话请求 | 升级客户端，提交前持久保存请求 UUID；不要自动重发旧 POST |
| 请求超时或提交响应丢失 | 查询原 request_key / 任务；确认没有原结果再明确重试 |
| 原远端结果未知 | 保留未知费用状态；明确接受重复计费风险后重试 |
| 大纲、理解快照、笔记或同步版本冲突 | 复制或保留原输入，重新读取版本，核对后再保存 |
| 语义准入失败、索引/模型/维度不匹配 | 继续用 FTS；核对冻结配置和质量记录，不自动开启 |
| 导出下载失效 | 重新选择范围、预览和确认；不用过期或撤回包 |
| 离线下载失败或被驱逐 | 保留待同步文字，检查配额后明确重新下载 |
| 离线授权失效 | 保留可复制的锁定文字，回在线站点登录和核对；不迁移旧操作到新会话 |
