# 检索优化实测（2026-10-02）

已实现独立检索角色、较小完整段落窗口、显式付费候选重排、本地问句边界处理、相关性反馈与有效对象导出。普通 GET 不请求模型；缓存未准备、材料版本变化或撤销权限时退回原排序。重排只调整前 30 条候选，后续排序保留，翻页不会重复已移动的对象。

## 固定对照

60 条公开编写的中文材料，20 个原有改写问题 + 20 个此前没有用过的提问。留出的是查询，不是独立领域或个人语料；标签由助手预先编写，没有人工评分。夹具位于 `internal/store/testdata/jina-retrieval-holdout.json`；测试会检查与原查询不重复。两次成功运行均使用相同夹具。

| 查询集 | 旧 text-matching 首位 / 前十召回 | 新 retrieval 首位 / 前十召回 | 新角色 + 重排首位 / 前十召回 |
|---|---|---|---|
| 原改写 20 条 | 75% / 100% | 85% / 100% | 95% / 100% |
| 留出提问 20 条 | 75% / 95% | 75% / 100% | 100% / 100% |

新角色改善召回，但不会使每个问题的排序都更好。重排也有明确退化：`rewrite-01`“读完合上书自测能帮助记忆吗”的正确材料从新角色第一位降到第十位，因此重排保持显式可选，未成为搜索默认路径。两组 FTS 在这些较长同义提问上依然为 0%；问句边界处理只改善保留实际概念词的问句（例如“工作记忆是什么？”），不声称它能替代语义检索。

成功报告：`legacy.json`、`retrieval.json`，逐查询结果与所有失败包含其中。两次报告均验证只读、缓存缺失回退、普通搜索质量门禁、权限撤销失效。较小窗口的完整段落及重叠、多窗口冻结/采用一致性另有离线测试；短材料夹具不能量化长播客窗口质量。

## 实际调用和费用

两次成功运行：88 次 embedding 请求，供应商报告 4,208 输入 tokens；40 次重排请求，供应商报告 49,112 输入 tokens。现金费用未知，没有登记或猜测 API key 的购买价格。

另保留 `initial-protocol-failure.log`：首次新角色运行已完成 44 次 embedding（2,104 tokens），随后首次重排被过严的 0～1 分数校验拒绝；该进程未导出这次重排的 token 回执，不能把它当作零费用，也不能用重跑结果补造。另经实际项目 `.env` 加载与 Selector 路由验证成功调用 embedding 和重排各一次，分别报告 9 和 187 tokens，见 `configuration-live.json`。总计 175 次请求，已知 55,620 tokens，另有一次重排实际 tokens 未保存；现金费用均未知。生产任务对已知但不可采用的响应保留用量回执。

[Jina OpenAPI](https://api.jina.ai/openapi.json) 定义 v5 默认 text-matching，以及 retrieval.query / retrieval.passage；重排分数定义为越大越相关的数值，不限定 0～1。[Jina 重排说明](https://jina.ai/reranker/)列出 v3.5。接口使用完整候选、每条最多 8192 字节，总请求最多 98304 字节，无自动重试或重定向。

## 启用与恢复

本地忽略的 `.env` 已配置 `LEARNING_EMBEDDING_PROFILE=jina-retrieval-v1` 和 Jina v3.5 重排连接；凭据使用提供的 JINA_API_KEY 实际值（环境文件按字面加载，不展开变量引用），没有提交。配置在重启后生效。新角色是独立索引身份，旧向量不混用；需在搜索设置明确预检、选择来源、重新建索引并通过原质量门禁。未修改个人数据库或远端服务配置，未外发 323 集个人节目。

搜索页“准备候选重排”明确确认外发和计费后入队；任务页面展示冻结估算、实际用量及原范围结果链接。未外发的失败任务或已有响应断点可明确恢复；远端未知且没有断点的任务阻止重放，需要先核对供应商记录，本次不提供重复付费的未知结果重试入口。

相关/不相关反馈存为 Owner 观察；导出最多 200 条当前有效对象的观察，记录 FTS、RRF 或重排方法，清理对象时删除关联反馈。导出不会自称质量门禁通过，也不会外发或自动训练。真实个人语料与人工评分仍需实际试用积累。

## 验证边界

全套 Go 覆盖率门禁、注释门禁、vet、构建和有关协议/配置/队列/存储/HTTP 的 race 测试作为离线验证。报告中的小语料延迟不能代表 1 万或 5 万窗口；本次没有重测大规模容量和性能。

此前远端 CI 的失败另定位到问答测试夹具默认第一项一定有段落的假设：当理解材料排在首位时越界。新增混合顺序测试先复现失败，随后修正夹具只选择有段落的来源证据；没有改变生产问答或权限规则。原权限撤销与接受历史测试通过 race 连续三轮验证。
