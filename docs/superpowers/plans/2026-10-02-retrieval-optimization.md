# Jina 检索优化实施与验收

目标：改善中文自然提问的排序，同时维持搜索只读、来源授权、版本失效、显式付费与未知结果不重放。

| 工作 | 实现 | 验收 |
|---|---|---|
| 检索角色 | 独立 `jina-retrieval-v1` 配置身份；文档 passage、查询 query；旧 ID 不变 | 协议、迁移、冻结路线与索引测试；真实模型对照 |
| 候选重排 | 独立配置；显式 POST 冻结前 30 项；任务快照无材料正文；预算、权限、检查点、回执、本地缓存 | 无 CSRF 拒绝；GET 不付费；未知不重放；撤销权限失效；跨页无重复 |
| 中文问句 | 只去掉边界提问用语，保留词项、原文片段与筛选权限 | 自然提问、英文/中文原有搜索回归 |
| 分段 | 新配置约 1536 字节窗口，最多重叠一个完整短段；超大完整段保留，8192 上限拒绝 | 旧窗口不变、完整段、不截断、多窗口采用与权限失效 |
| 独立评测与反馈 | 固定 20 个未用过的提问，复用 20 改写作为诊断；60 项人工编写公开语料；Owner 反馈及有效对象导出 | 固定标签、旧/新角色同集比较、重排报告；不冒充个人语料或人工验收 |

原子任务：配置与迁移 → 协议角色 → 窗口与采用一致性 → 重排接口 → 持久任务与预算 → 本地缓存分页 → POST/界面 → 中文问句 → 反馈 → 固定 holdout → 离线门禁 → 付费对照 → 结果与配置文档 → 提交推送。

真实模型验证仅外发上述公开编写夹具；不读取或外发个人数据库。供应商 token 使用与未知现金费用分别报告。真实个人语料及人工评分需要后续实际使用反馈，不能由程序自动宣称完成。新版向量需重新显式选择来源、准备索引并通过既有质量门禁，不能复用旧身份直接开启。

完成记录：上述原子任务已实现并通过本地门禁；真实对照见 `docs/superpowers/validation/jina-retrieval-v2/README.md`。个人语料与人工评分仍属后续试用证据，不标为通过。提交后的远端 CI 状态须单独查看。
