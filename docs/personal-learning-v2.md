# 个人听学与知识文章使用说明

本轮在现有 Go、SQLite 和浏览器界面上完成个人学习流程。首页、节目详情、笔记/重点、搜索、知识文章和回顾构成日常入口；旧创作工作台、精读、DJ、图谱和任务页面继续可用。

## 收听与记录

首页的“继续听”分别显示原音和 DJ 的最近位置。打开节目不会自动播放；选择继续或播放后才开始。显式时间/片段链接优先于续听。倍速、前后15秒、睡眠定时和媒体控制由共用播放器处理，DJ 保留原音与解说切换。

不同模式分别保存进度，多标签或多设备发生版本冲突时，需要明确选择保存本次位置。断网后保留本地待存位置；恢复联网后继续校验版本。页面关闭前的请求不保证必达。没有 JavaScript 时，节目详情仍提供浏览器基础音频控件。

“记一下当前播放位置”保存我的理解；选择原文后可创建来源笔记。保存时自动关联真实片段和来源快照，无须输入 JSON。DJ 解说期间记录的是个人理解，关联解说参考的原音，不把解说当作原文。没有可靠快照的旧清单会明确提示；原音被替换后不能用新文件冒充旧位置。

笔记修改保留实际修订历史。失败或版本冲突保留表单草稿，需核对最新版本后重新提交。来源重新分析不自动移动旧笔记锚点。旧内容可在冻结依据页查看；原音身份无法确认时只展示原文，不假装准确回听。

## 找回学习成果

“笔记/重点”可按来源筛选，链接到笔记修订和原始依据。统一搜索覆盖音频原文、文档、重点、来源笔记、个人理解和知识文章段落；默认搜索当前通过文章，草稿与历史需主动选择。搜索和首页 GET 不调用外部模型。

检索使用 SQLite 本地全文索引与明确的中英文词汇别名，适合文字相关的查找，不承诺一般跨语言语义理解。索引随业务修改同步维护；损坏时会报错而非返回伪空结果。外部 SQLite 工具缺少应用注册的索引函数，不能直接写业务表。

## 自动知识文章

在“知识文章”立即发现问题，或限定节目、来源、主题、日期及具体材料。历史探索按最多20项的学习变更批次推进，可选择从头或继续。程序先用新材料作为种子，检索相关历史笔记，再由模型判断支持、补充、反方和缺口；本地召回只代表文字相关。

发现批次与候选方向分别保存。同一批材料可以形成不同问题；重复点击同一方向复用文章。候选等待时可手动成稿，自动化开启后也可按额度继续处理。与已有问题重复会阻断；续篇需要真实新增材料或版本、明确增量及历史文章关联，换标题不能代替增量。

后台默认关闭，在“自动生成与文章偏好”明确开启。每5分钟检查一次，按等待时间、每日自动篇数、单个在途文章和月预算接纳任务。候选最多20项，完整材料最多40KB，单项最多10KB；超过上限保留程序舍弃记录，不把截断片段当完整依据。默认不联网补事实，也不自动发布。

文章按发现 → 选材 → 写作 → 审校运行，未通过时最多自动修订一次，再审后保留待审状态。材料不足会保留问题与缺口。来源整理、个人笔记、AI 综合分别显示；来源链接由程序生成，逐字引语必须与冻结原文一致。

阅读默认选择最近通过版；新的工作稿不会覆盖它。可手动编辑、补材料、定向 AI 修订或单独再审。每次保存形成不可变修订，审校绑定确切正文与材料。下载只允许通过且依据仍有效的版本。来源、重点或笔记变化会提示失效，需要重新处理。反馈不会静默改变写作偏好。

失败可显式重试。已保存且合法的响应通过断点恢复，不重复调用或记账；远端开始但结果未保存时标为未知，停止自动重放。显式重试未知结果可能再次付费，原尝试与费用记录仍保留。

## 每周回顾

“回顾”可以手动生成本周问题，也可独立开启后台回顾。开启回顾不会开启文章自动生成，反之亦然。默认时区 UTC；可选择 IANA 时区、星期和当地时间，调度使用当地时间，审计使用 UTC。

每周窗口从当地周一开始，输入和窗口冻结，同一周重复生成复用同一批次。收集本周学习变化及待回看材料，每批最多5个解释问题。先用自己的话回答、自评能解释/部分理解/需要重看，或主动查看依据；依据在此之前不写入页面正文。AI 提供参考提示，不给未经验证的掌握度评分。

解释保留版本，可以稍后回看；只有明确选择“保存为个人笔记”才建立新的个人理解，不覆盖来源笔记。没有材料不会付费生成，来源变化会提示核对旧依据。

## 配置、费用与升级

复用 `.env` 的 `POD_BASE_URL`、`POD_API_KEY`、`POD_MODEL`。可设置 `POD_REVIEW_MODEL` 单独审校；不设置时沿用 `POD_MODEL`。修改环境后需重启。密钥不进入页面、文章或报告，不影响既有转录、学习与创作模型配置。

文章阶段和回顾批次保留模型、提示版本、输入/输出用量和费用。价格来自 Owner 配置的价格表；没有价格时显示“未知”，不能当作零费用。预算规则沿用现有机制；要按金额限制调用，应先配置相应模型价格。

升级前使用现有 `cloudwisepod backup` 保存数据库和证据文件。迁移0057–0062按顺序自动应用：播放模式、笔记历史、文章修订、检索、发现批次、每周回顾。旧记录按已知内容回填；不伪造不存在的旧笔记正文、检索判断或音频身份。备份恢复到全新目录后用当前程序打开，不能让旧程序直接读取新 schema。

当前验证范围见[第二轮验收记录](superpowers/plans/2026-10-01-personal-learning-and-knowledge-articles-v2-validation.md)。真实节目内容评分和手机锁屏/后台体验需要各自的实际验收证据。
