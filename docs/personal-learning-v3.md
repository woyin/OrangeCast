# 第三轮个人听学使用说明

第三轮延续[已有个人学习流程](personal-learning-v2.md)。各阶段实现和验证见[第三轮验收记录](superpowers/plans/2026-10-01-personal-learning-and-knowledge-articles-v3-validation.md)；真实笔记质量、手机后台和真实ASR验收仍待验证。

## 持续收听与学习问题

主要学习页面切换时保留同一个播放会话。稍后听支持加入、移动、移除和继续；打开队列不自动播放。录音和文字笔记始终关联实际播放器的来源，页面当前展示的来源可能不同。

在“学习问题”记录想弄懂的问题、目标与个人进展，明确关联材料和文章。关联不代表证据成立；问题可以暂停、解决或归档。材料改变仍保留历史身份，需要核对后再确认。

## 更新已有文章

“文章更新”可以检查已有文章的新材料。接受提案后形成工作稿并重新审校，最近通过版继续保留。旧父稿、依据变化或删除会阻断过期提案；忽略、稍后和接受分别保留记录。更新自动开关默认关闭，与新方向发现独立。

## 录音笔记

播放节目时点击“录音笔记”，立即冻结原来源和原音位置。等待麦克风权限时继续播放，真正开始录音才暂停。权限失败会打开原位置的文字笔记入口。录完由你点击“继续节目播放”。

每段最多5分钟／20MB，服务器检查实际格式和解码时长。浏览器会按支持的格式选择录音；需要安全上下文、可用麦克风及MediaRecorder支持。手机应通过HTTPS访问。后端需要ffmpeg和ffprobe。

“停止并留草稿”只写入本地；“停止并转写”或“上传并转写”明确上传并启动ASR。查看列表、恢复本地草稿、切页或刷新状态不启动转写。本地最多10条／50MB，保存失败会明确提示，内存中的文字仍可复制。退出登录清理当前会话的私有草稿，不能将其当作永久保存。

转写建议单独显示，不会覆盖你在等待期间写的文字。“采用转写”明确替换草稿文字，核对后才能保存为个人理解笔记。保存和采用响应等待期间文字暂时锁定；转写等待期间仍可编辑。保存可同时关联学习问题，重复保存只生成一条笔记。语音草稿不进入检索或文章选材，只有正式保存的笔记进入学习材料。

未保存服务器草稿7天后清理。正式保存时默认安排删除录音，勾选“保留录音”才长期私有保存；下载需要登录。清理失败保留删除意图，后台会重试。删除草稿不会删除已经发生的用量或未知远端结果；显式重试未知调用可能再次计费。

## 转录配置与预算

未设置语音专用配置时沿用站内转录provider/model。可在`.env`设置`VOICE_ASR_PROVIDER`、`VOICE_ASR_MODEL`；独立音频连接使用成对的`VOICE_ASR_BASE_URL`与`VOICE_ASR_API_KEY`，并明确provider/model。支持Groq与OpenAI音频接口，不将POD文本连接当音频端点。环境改变需重启，任务保留冻结的模型和端点身份；端点变更会阻断旧任务的隐式切换。

节目转录需要真实片段时间戳。只返回文本的模型可以转写个人理解，但不能伪造节目片段位置；节目处理会保留响应并提示明确选择支持时间戳的模型。

在“语音笔记”的预算价格表登记确切provider/model的每分钟预估金额（美元分）。节目与语音转录均按经过探测的时长冻结估价，不能套用文本token价格。配置月预算但未登记音频价格时先阻止调用。预估不是供应商账单；没有可核实的实际计量价格时实际费用显示未知，并保留远端调用事实。

## 备份与恢复

`cloudwisepod backup`使用一致性数据库快照，备份格式升级为v2，并继续恢复v1。v2额外包含已经保存且明确保留的私有录音，检查文件名、长度与SHA256，恢复录音保持0600权限。私有目录默认是`DATA_DIR/voice-notes`。

临时草稿录音不进入长期备份。恢复后可以保留草稿文字及历史位置；录音文件不存在时页面明确提示，仍可编辑并保存文字。退出登录、本地清理和备份不替代正式保存笔记。

备份恢复在独立目录进行；回退旧程序时恢复旧程序对应的完整备份，不让旧程序直接读取升级后的schema。
