# 第三轮个人听学使用说明

第三轮延续[已有个人学习流程](personal-learning-v2.md)。各阶段实现和验证见[第三轮验收记录](superpowers/plans/2026-10-01-personal-learning-and-knowledge-articles-v3-validation.md)；真实个人笔记质量与手机后台体验仍待验证。自建短音频的真实ASR接口已通过技术验证，详见[综合验收报告](acceptance/2026-10-personal-learning-v3.md)。

## 持续收听与学习问题

主要学习页面切换时保留同一个播放会话。文章列表点击生成也保留播放；无JS时沿用普通表单跳转。稍后听支持加入、移动、移除和继续；打开队列不自动播放。录音和文字笔记始终关联实际播放器的来源，页面当前展示的来源可能不同。

在“学习问题”记录想弄懂的问题、目标与个人进展，明确关联材料和文章。关联不代表证据成立；问题可以暂停、解决或归档。材料改变仍保留历史身份，需要核对后再确认。

## 更新已有文章

“文章更新”可以检查已有文章的新材料。接受提案后形成工作稿并重新审校，最近通过版继续保留。旧父稿、依据变化或删除会阻断过期提案；忽略、稍后和接受分别保留记录。更新自动开关默认关闭，与新方向发现独立。

## 录音笔记

播放节目时点击“录音笔记”，立即冻结原来源和原音位置。等待麦克风权限时继续播放，真正开始录音才暂停。权限失败会打开原位置的文字笔记入口。录完由你点击“继续节目播放”。

每段最多5分钟／20MB，服务器检查实际格式和解码时长。浏览器会按支持的格式选择录音；需要安全上下文、可用麦克风及MediaRecorder支持。手机应通过HTTPS访问。后端需要ffmpeg和ffprobe。

“停止并留草稿”只写入本地；“停止并转写”或“上传并转写”明确上传并启动ASR。查看列表、恢复本地草稿、切页或刷新状态不启动转写。上传断网失败时草稿仍在本地；重新联网、刷新后可点击“查看本地草稿”再打开，明确上传或保存。浏览器清理站点数据仍可能丢失未正式保存的草稿。本地最多10条／50MB，保存失败会明确提示，内存中的文字仍可复制。退出登录清理当前会话的私有草稿，不能将其当作永久保存。

转写建议单独显示，不会覆盖你在等待期间写的文字。“采用转写”明确替换草稿文字，核对后才能保存为个人理解笔记。保存和采用响应等待期间文字暂时锁定；转写等待期间仍可编辑。保存可同时关联学习问题，重复保存只生成一条笔记。语音草稿不进入检索或文章选材，只有正式保存的笔记进入学习材料。

未保存服务器草稿7天后清理。正式保存时默认安排删除录音，勾选“保留录音”才长期私有保存；下载需要登录。清理失败保留删除意图，后台会重试。删除草稿不会删除已经发生的用量或未知远端结果；显式重试未知调用可能再次计费。

## 转录配置与预算

未设置语音专用配置时沿用站内转录provider/model。可在`.env`设置`VOICE_ASR_PROVIDER`、`VOICE_ASR_MODEL`；独立音频连接使用成对的`VOICE_ASR_BASE_URL`与`VOICE_ASR_API_KEY`，并明确provider/model。支持Groq与OpenAI音频接口，不将POD文本连接当音频端点。环境改变需重启，任务保留冻结的模型和端点身份；端点变更会阻断旧任务的隐式切换。

节目转录需要真实片段时间戳。只返回文本的模型可以转写个人理解，但不能伪造节目片段位置；节目处理会保留响应并提示明确选择支持时间戳的模型。

在“语音笔记”的预算价格表登记确切provider/model的每分钟预估金额（美元分）。节目与语音转录均按经过探测的时长冻结估价，不能套用文本token价格。配置月预算但未登记音频价格时先阻止调用。预估不是供应商账单；没有可核实的实际计量价格时实际费用显示未知，并保留远端调用事实。

## 备份与恢复

`cloudwisepod backup`使用一致性数据库快照，备份格式升级为v2，并继续恢复v1。v2额外包含已经保存且明确保留的私有录音，检查文件名、长度与SHA256，恢复录音保持0600权限。私有目录默认是`DATA_DIR/voice-notes`。

临时草稿录音不进入长期备份。恢复后可以保留草稿文字及历史位置；录音文件不存在时页面明确提示，仍可编辑并保存文字。退出登录、本地清理和备份不替代正式保存笔记。

备份恢复在独立目录进行；回退旧程序时恢复旧程序对应的完整备份，不让旧程序直接读取升级后的schema。

## 每日短回顾

从“回顾”进入“每日短回顾”，复用每周已生成的题目和冻结依据，不启动新的AI请求。默认每次3题，可选择1–5题；未结束会话可继续，结束后未回答题仍保留到期安排。

先写自己的解释，再选择自评。主动查看依据保留未提交文字和自评，但不算作答。提交解释将回答历史和下次到期一起保存；明确保存为笔记才生成个人理解笔记。历史回答可以单独保存，不覆盖新回答。

“需要再看”安排约1个日历日，“部分理解”约3日，“能解释”约7日，连续两次约14日。这是个人安排，不表示科学测量了掌握程度。稍后一天不算作答。偏好使用IANA时区；新安排按当地日历计算，修改时区不重算已有UTC到期。

可以手动修改到期、暂停、恢复或结束单题，也可关联学习问题。关联问题暂停或归档时，对应题目不进入新会话；独立题目不受影响。依据修订时保留原版本并提示，依据撤回或来源删除时阻止继续采用。双窗口旧修订会冲突并保留输入，需核对后重新提交。

## 任务与成本

“任务与成本”统一查看知识文章发现/生成、增量更新、每周生成和语音转录。详情展示冻结模型、提示版本、材料、估算、已保存断点、预算预占、错误和原恢复入口。旧任务没有记录的原因或准确调度时间显示未记录，不调用AI补造。

费用显示学习调用的已知小计和未知费用任务/旧调用身份，包含节目转录。未知部分不当作免费或完整总额；已知响应重试复用原付费身份，不另算一笔费用。音频秒、文本单位和美元分分别显示。

暂停类别或方向会阻止新任务和后续阶段，持续到明确恢复；恢复不会自动重放未知结果。文章发现、更新、每周生成的自动开关仍独立且默认关闭；暂停不会改变这些开关。

停止排队任务后它仍可见但不会被领取；尚未外发的排队任务可以明确恢复。运行任务的停止请求在阶段边界生效；已发出的请求仍保存响应与用量，迟到响应不自动采用为成果。不能保证供应商停止计费。优先级只影响合格且尚未领取的任务，不能绕过材料策略或预算。

所有控制动作填写理由并保存修订与历史。领取会增加控制修订，旧窗口操作可能冲突；冲突保留原输入，需要核对后再提交。列表可见时每10秒更新状态文字，不刷新正在编辑的表单；新任务和筛选结果需明确刷新。
